# Movie watchlist as a ticket scrapbook.

## Base features
- search, add, remove movies from list, mark them as watched, 
- You can mark movies as favorites
- login/signup

## Fun features
Turn your movie history into a digital scrapbook.
- When you mark a movie as watched, the app generates a unique, stylized ticket that resembles physical tickets.
- To 'mark as watched' you tear the ticket and only a stub remains

## Other features
- bulk import from other services so that users don't have to add each movie manually
- proper search feature
- connect movie database
